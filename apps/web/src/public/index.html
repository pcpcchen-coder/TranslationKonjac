How to test

  1. For Chrome tab mode: open a tab playing audio, then share that tab with tab audio enabled.
  2. For microphone mode: choose Microphone, allow mic access, then play phone/app audio near the computer mic.
  3. For two-way call mode with LINE Web: choose the call tab for their English audio.
  4. For two-way call mode with LINE app: set LINE speaker/output to BlackHole 16ch, then choose that device as “Their voice source”.
  5. Pick the target language for one-way mode, start translating, and listen for translated speech.
