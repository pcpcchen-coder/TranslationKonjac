# build resources

`electron-builder` reads packaging and signing resources from this folder.

- `entitlements.mac.plist` — hardened-runtime entitlements (audio input, network
  client, JIT for Chromium).
- `icon.png` — 1024×1024 app icon source. Generated by `npm run make-icon` and
  git-ignored; `npm run dist:mac` regenerates it before packaging. Replace the
  generator (`scripts/make-placeholder-icon.mjs`) with a real branded icon before
  shipping.
